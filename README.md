# ULY MURA SCAN · Ақтөбе

Веб-приложение: наводишь камеру телефона на памятник или табличку улицы — открывается историческая карточка. Языки: қазақша, русский, English.

Сайт: https://shyngly29-bit.github.io/tarih-scanner-aktobe/

## Как устроено распознавание (без сторонних ИИ-сервисов)
- **TensorFlow.js** — открытая библиотека машинного обучения (Apache 2.0), работает прямо в браузере.
- **MobileNet v1 0.25** (`model/mobilenet/`) — предобученная нейросеть, превращает фото в 256 чисел-признаков.
- **Наш классификатор** (`model/classifier.json`) — обучен на наших фотографиях на странице `train.html`.
- Код приложения, страницы обучения, тексты и переводы написаны с помощью Claude (claude.ai, бесплатная версия).

## Как переобучить модель
1. Разложите фото по папкам: `dataset/<класс>/...` (названия классов — как `id` в `data.js`, плюс `fon` для фона).
2. Откройте `train.html` (на сайте: `…/tarih-scanner-aktobe/train.html`).
3. Выберите папку `dataset`, при желании — папку с проверочными фото, нажмите «Оқытуды бастау».
4. Скачайте `classifier.json` и замените файл в `model/`. Загрузите на GitHub (Add file → Upload files).

Текущая модель: 8 классов, 117 фото; на 20 проверочных фото верно 19 (95%).

## Файлы
- `index.html` — приложение; `ml.js` — распознавание и обучение; `train.html` — обучение.
- `data.js` — исторические данные (русский оригинал); `i18n.js` — интерфейс и переводы карточек (kk, en).
- Ссылки: `#lang=kk|ru|en`, `#catalog`, `#obj=<id>`.

## Запуск на компьютере
В папке `app`: `python -m http.server 8000`, затем http://localhost:8000. Камере на телефоне нужен https (GitHub Pages).

Факты сверять с краеведческим музеем (п. 4.8 положения). Переводы kk/en — дать вычитать учителям.
