# Тарих Сканер · Ақтөбе — инструкция

ИИ-платформа (единственная, п. 4.3 положения): **Google Teachable Machine** — https://teachablemachine.withgoogle.com (бесплатно).

## 1. Сделать фото (датасет)
Для каждого объекта — 30–50 своих фото: разные ракурсы, расстояние, утро/вечер. Людей в кадре быть не должно (п. 4.10).
Отдельный класс **`fon`** — 50+ фото случайных зданий, дорог, неба (чтобы ИИ не «угадывал» на всём подряд).

## ⭐ Сейчас (1-й этап): только пр. Абулхаир хана и пр. Молдагуловой
Классы: `fon`, `abulkhair`, `baiganin`, `patsaev`, `nurdaulet`, `street_abulkhair`, `heroes_square`, `obelisk`, `moldagulova_memorial`, `sankibai`, `moldagulova_museum`, `street_moldagulova`.
Остальные объекты сохранены в `data.js` и включатся, если добавить их зону в `ZONES`.

## 3. Экспорт
Export Model → Tensorflow.js → **Download**. Из архива положить 3 файла в папку `app/model/`:
`model.json`, `weights.bin`, `metadata.json`.

## 4. Запуск
- **На компьютере:** в папке `app` выполнить `python -m http.server 8000` и открыть http://localhost:8000
- **На телефоне** камере нужен https. Самый простой путь: перетащить папку `app` на https://app.netlify.com/drop — получите https-ссылку.
- Без сервера (двойной клик по index.html) работает каталог и кнопка «Загрузить модель (3 файла)».

## 5. Добавить объект
Добавить запись в `data.js` (поле `id` = имя класса) и обучить модель с новым классом.

## Для защиты (баллы)
- Посчитайте точность: снимите по 10 новых фото каждого объекта, запишите, сколько распознано верно → «точность 9X%» (критерий 8).
- Факты в `data.js` сверить с краеведческим музеем (п. 4.8).

## Языки (қазақша / русский / English)
- Переключатель ҚАЗ · РУС · ENG в шапке, выбор запоминается. По умолчанию — язык телефона (если не kk/ru/en — казахский).
- Тексты интерфейса и переводы карточек — в `i18n.js` (`UI` и `OBJ_I18N`). Русский оригинал карточек — в `data.js`.
- Ссылки: `#lang=kk`, `#lang=en`, `#catalog`, `#obj=heroes_square` (можно комбинировать: `#lang=en&obj=obelisk`).
- Казахский и английский переводы сделаны ИИ — дать вычитать учителям языков.
